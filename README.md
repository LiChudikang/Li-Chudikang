## Featured Project

### 🤖 [tevo-research-agent](https://github.com/LiChudikang/tevo-research-agent)

> AI-powered market research agent that validates business concept demand using multi-platform data collection and LLM-driven semantic analysis.

**What it does:**
- Collects data from Google Trends, YouTube, TikTok, Instagram, Twitter, and Google Maps
- Uses Claude (Anthropic) to identify behavior patterns and validate hypotheses
- Generates structured PDF/Markdown reports with demand certainty scores

**Stack:** `Python` · `Claude API` · `Supabase` · `Jinja2` · `WeasyPrint`
